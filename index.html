To the right is what is called light reactive art which shows different images layered on top of each other in cyan, magenta, and yellow. Simply select a color below, drag the circle over image to see the hidden images!
With green you are able to see the magenta layer. The color magenta is associated with love so the imagery you see evokes a romantic feeling.
With red you are able to see the cyan layer. The color cyan is associated with peace so the ocean imagery you see envokes peace and calm feelings.
With blue you are able to see the yellow layer. The color yellow is associated with joy so the imagery you see displays hapiness and humor.
